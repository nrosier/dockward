# Security Policy

## Reporting a vulnerability

Please report security vulnerabilities privately. Do not open a public issue, pull request, or discussion for a security problem.

1. Open the repository's **Security** tab on GitHub.
2. Select **Report a vulnerability**.
3. Describe the issue, the affected version or commit, and steps to reproduce it.

This uses GitHub private vulnerability reporting, which keeps the report visible only to the maintainers until a fix is ready.

Do not include live tokens, keys, or hostnames in the report. Redact them and describe their type instead.

## Response

We aim to acknowledge a report within 7 days. This is a target, not a guarantee. We will keep you updated as we assess the issue and work on a fix.

## Supported versions

Only the latest tagged release receives security fixes. Older releases and the `main` branch are not supported for security patches.

## Disclosure

Please allow us time to release a fix before any public disclosure. We will credit reporters in the advisory unless you ask us not to.
