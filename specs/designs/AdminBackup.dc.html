Backup

Writes an encrypted copy of the database to the backup folder on the server. Only the same encryption key can restore it.

Backup written /data/backups/harborgate-20261103T140512Z.hgbk

Keep your encryption key for as long as you keep backups made with it. After a key rotation, older backups still need the old key.

Restore

Restore runs from the command line with HarborGate stopped. It is not available in the browser.

  1. Stop the HarborGate container.
  2. Run the restore command with the same HARBORGATE_ENCRYPTION_KEY that made the backup: 
    harborgate restore /data/backups/harborgate-20261103T140512Z.hgbk
  3. Start HarborGate again. The audit log records the restore.

Full steps are in docs/SETUP.md.
