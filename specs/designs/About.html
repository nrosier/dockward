Behaviour (for review)
  • Opened by clicking the header version. Closes with Escape, the Close button, or a click outside. Focus returns to the version button on close.
  • Scanner versions come from the backend, read at startup from the bundled binaries. If a read fails, the row shows unknown and startup continues.
  • Licence texts are read from files in the image. The Trivy and Grype rows link to their full text in the same dialog, not an external site, so it works offline.
  • Every label and value is a catalog key in en.json. The dockward and scanner version rows use the same monospace style as the header.
